## Database Setup

The server persists to the `python-fastapi` database on the shared PostgreSQL instance.

**1. Start PostgreSQL:**

```bash
cd ../database
docker compose up -d
```

**2. Create the database and apply the schema:**

```bash
./create-databases.sh
./apply-schemas.sh
```

**3. Configure credentials** — copy `.env.example` to `.env` and edit:

```bash
cp .env.example .env
```

Available environment variables (all optional; defaults match `database/.env`):

| Variable          | Default         | Description                          |
|-------------------|-----------------|--------------------------------------|
| `DATABASE_URL`    | —               | Full DSN — overrides all vars below  |
| `POSTGRES_HOST`   | `localhost`     | Database host                        |
| `POSTGRES_PORT`   | `5434`          | Database port                        |
| `POSTGRES_USER`   | `myuser`        | Database user                        |
| `POSTGRES_PASSWORD` | `mypassword` | Database password                    |
| `POSTGRES_DB`     | `python-fastapi`| Database name                        |

## Installation & Usage

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the server:

```bash
# Load .env credentials, then start
set -a && source .env && set +a
PYTHONPATH=src uvicorn petstore.main:app --host 0.0.0.0 --port 8080
```

Open your browser at `http://localhost:8080/docs/` to see the interactive API documentation.

## Running with Docker

```bash
docker compose up --build
```

Set DB credentials in the container by passing environment variables or extending `docker-compose.yaml`.

## Implementation Notes

CRUD operations are implemented in `src/petstore/petstore/impl/`:

- `pet_api_impl.py` — `PetApiImpl`: add, update, get, find by status/tags, update with form, delete, upload file (image data not persisted).
- `store_api_impl.py` — `StoreApiImpl`: inventory (grouped by pet status), place/get/delete order.
- `user_api_impl.py` — `UserApiImpl`: create, create-with-list, login, logout (stateless), get by username, update, delete.

The connection pool is created lazily on the first request. JSON/JSONB columns are automatically decoded to Python objects.
